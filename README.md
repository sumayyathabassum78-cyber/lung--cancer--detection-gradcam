
# Iris Flower Classification Using Machine Learning

## Project Overview
This beginner-friendly machine learning project predicts the species of an Iris flower from four measurements: sepal length, sepal width, petal length, and petal width.

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas

## Machine Learning Algorithm
Random Forest Classifier

## Features
- Interactive measurement sliders
- Flower species prediction
- Estimated prediction probabilities
- Test-set accuracy display

## Dataset
The project uses the built-in Iris dataset provided by Scikit-learn.

## How to Run
1. Install Python 3.10 or later.
2. Download or clone this repository.
3. Install the dependencies:

   `pip install -r requirements.txt`

4. Start the application:

   `streamlit run app.py`

## Learning Objectives
- Understand supervised machine learning
- Train and evaluate a classification model
- Build a simple interactive web application

## Disclaimer
This project is for educational purposes. Predictions and evaluation results are not guarantees of real-world performance.
